# Bravura and SMuFL assets

- `Bravura.otf` and `Bravura.json` are from the [Bravura 1.482 release](https://github.com/steinbergmedia/bravura/releases/tag/bravura-1.482). The font is distributed under the SIL Open Font License in `OFL.txt`.
- `smufl_glyph_names.json` contains only glyph name and codepoint pairs derived from the [SMuFL standard metadata](https://github.com/w3c-cg/smufl/blob/f9d12b22ea89978720ba9defb2f4df67fabd8564/metadata/glyphnames.json) at commit `f9d12b22ea89978720ba9defb2f4df67fabd8564`. It is standard mapping data, not source code or a software dependency.
- `NotoSerif[wdth,wght].ttf` is the variable text face from the [Google Fonts Noto Serif family](https://github.com/google/fonts/tree/main/ofl/notoserif), distributed under the [SIL Open Font License 1.1](NotoSerif-OFL.txt). It is used for page titles, composer credits, and other shaped text. SHA-256: `4d8e6761424656867019081a1a01336f3cb086982682698714054fc33f782713`.
- `NotoSerif-OFL.txt` is the license accompanying that font. SHA-256: `cee9892f9f0cc8fe882c9e9537ee6a89621d86ee7ceaf70b02e2b2b1c25c061a`.
